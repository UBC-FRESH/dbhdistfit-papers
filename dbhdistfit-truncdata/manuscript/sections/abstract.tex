\begin{abstract}
Stem diameter distributions underpin many forestry applications, yet inventory datasets are routinely truncated by merchantability limits and maximum expected diameters. Best practice fits truncated forms of target distributions, but those variants are not always published or implemented in common software, prompting analysts to rely on biased complete-form fits. We present a two-stage weighted least-squares procedure that keeps the complete-form implementation while reproducing the truncated solution. Applied to permanent sample plot data from Qu\'ebec, Canada, the method matches the reference truncated fits across Weibull and gamma families to within machine precision. The accompanying code base regenerates all figures, tables, and manuscript artefacts, providing a turnkey workflow for practitioners facing doubly truncated tally data.
\end{abstract}
